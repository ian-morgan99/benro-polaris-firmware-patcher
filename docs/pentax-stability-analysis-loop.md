# Experiment-analysis loop

```text
hypothesis
 -> smallest discriminating scenario
 -> deterministic execution
 -> structured trace + logs
 -> first-divergence fingerprint
 -> A/B/A repeat
 -> source attribution
 -> focused issue + regression
 -> smallest deterministic fix
 -> pre/post repeat
 -> adjacent baselines
 -> broader/E2E qualification
```

Agents should iterate this loop rather than running the entire matrix and then attempting one large retrospective diagnosis.
