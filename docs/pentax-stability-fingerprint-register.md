# Failure fingerprint register

`tests/pentax_stability_failure_fingerprints.csv` is the compact cross-run register.

Add a row only after a first-divergence fingerprint has been observed. Do not pre-populate expected failures as if they were evidence.

Update failures/runs as experiments repeat. Link each mature fingerprint to a focused owning issue. Keep #82 as the umbrella rather than using it as the only defect tracker.
