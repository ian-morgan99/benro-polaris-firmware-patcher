# This is not just a timeout project

The 100-second constant is an important hypothesis because astro use exposes its architectural weakness, but the stability campaign must not collapse into "increase the timeout".

Independent causal families already deserve testing: candidate finalisation, command concurrency/preview, pgphoto process/session lifecycle, true USB transitions and upper-layer pressure.

A mode-aware design also requires correct candidate ownership and deterministic serialization even if every timeout were infinite.
