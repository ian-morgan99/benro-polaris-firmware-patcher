## 7. Standing constraints

- This repository distributes **no firmware**; never commit blobs or FwPkt material.
- Never read an offline GREEN as device qualification (#203/#216).
- Keepalive must be armed for every session (**#339**) — the radio sleeps ~60 s after the last
  client disconnects, which is what cut off this session's access.
- Connecting to the mount while unaligned makes the Benro app demand compass calibration;
  `link_wanted()` (`polaris-httpd.c:3073`) gates this deliberately. "Not connected" is correct
  behaviour on an unaligned head, not a fault.
