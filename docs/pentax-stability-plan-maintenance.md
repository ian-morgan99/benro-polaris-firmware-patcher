# Maintaining the stability plan

The v1 matrix is not sacred. Update it when hardware evidence makes a scenario redundant or identifies a better discriminator.

Rules:

- preserve run provenance and negative results;
- do not rewrite measured facts to match a theory;
- version material semantic changes to the plan;
- keep destructive tests staged after non-destructive characterisation;
- convert proven findings into focused regressions so the broad exploratory matrix can shrink over time.
