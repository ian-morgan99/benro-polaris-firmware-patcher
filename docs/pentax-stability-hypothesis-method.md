# Pentax stability hypothesis method

Use `tests/pentax_stability_hypotheses.csv` as the falsifiable hypothesis register.

For each hypothesis:

1. state what observation would support it;
2. state what observation would weaken/falsify it;
3. choose the smallest discriminating experiment;
4. run enough repeats to estimate reproducibility;
5. preserve negative results;
6. update the hypothesis status only from evidence.

This prevents the investigation from converging prematurely on whichever recovery symptom is easiest to see.
