# o-v17a re-verification — 2026-10-14 (SHIM #6 toolchain rebuild + full gate)

Companion to `SUMMARY.md` (2026-10-12). This round rebuilt o-v17a from source in
the host cross-toolchain (no container), re-ran the complete pre-release gate,
and armed the autonomous SD install path.

## 1. Why a rebuild was needed

The 2026-10-12 build used the container toolchain. To make the build reproducible
on the host (and to keep the SHIM #6 source changes in one tree), o-v17a was
rebuilt with the host `arm-linux-gnueabi` cross-toolchain. The rebuild is
**toolchain-only**: identical source, identical patches; only the compiler/binutils
provenance differs.

## 2. Toolchain repairs (host sandbox)

The host cross-compiler needed shims in `/work/bin/` + staged shared libs in
`/tmp/hostlibs/`:

| Item | Fix |
|---|---|
| `arm-linux-gnueabi-gcc` / `g++` | host gcc-13 with `--sysroot=/work/sysroot-armel -nostdinc -I<compiler-inc> -I/work/arminc` (ARM glibc headers from arminc beat the build's `-I/usr/include` x86_64 set; compiler's own dir supplies `stddef.h`/`limits.h`) |
| `arm-linux-gnueabi-readelf` | via host dynamic linker (`/run/host/lib64/ld-linux-x86-64.so.2`) |
| `/tmp/hostlibs/` | staged host toolchain shared libs: libisl, libmpc, libbfd (armel + **system**), libopcodes, libsframe, libctf, libjansson, **liblzma 5.8.3** (replaced the older host copy so `xz` finds `XZ_5.6.0`) |
| `build_ptp2.sh` | skip `tests`, `examples`, `packaging`, `doc` subdirs (their executables hit the sysroot DSO issue; only libs + camlibs are needed) |
| stale `config.status` | removed from `/work/lgsrc` (an earlier ptp2-only run had left it, causing configure to be skipped and dropping pentax from the camlib set) |
