# Measurement-first Pentax support

Where Pentax behaviour is undocumented or ambiguous, the connected physical camera is an engineering asset. Use controlled measurements to establish actual state/output semantics before encoding assumptions.

This is particularly important for Pixel Shift, long-exposure NR, Bulb, multi-output DNG+JPEG and which PTP conditions are safe to query during camera-side work.

Measured behaviour should be recorded with camera model/firmware because K-3 III observations are not automatically K-1 II rules.
