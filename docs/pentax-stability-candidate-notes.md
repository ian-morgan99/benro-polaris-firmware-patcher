# Candidate lifecycle stability notes

A successful transfer of one image does not necessarily mean a multi-output Pentax capture is terminal.

For each capture, discover all camera-reported candidates/descriptors and determine which belong to the initiated exposure. Track each through intended transfer/retention/reconciliation policy.

The next shutter is the strongest practical terminal proof: if the camera reports a previous transfer candidate still pending, the prior host completion was premature or reconciliation semantics were wrong.

Do not weaken a stale-candidate safety barrier merely to make the next shutter fire. Resolve ownership/finalisation correctly while preserving user DNG data.
