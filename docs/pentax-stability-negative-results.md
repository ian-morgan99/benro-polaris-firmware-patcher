# Negative experiment results matter

Record experiments that **do not** reproduce a failure.

Examples: if preview injection during EXPOSING is clean across repeated runs but the same injection during PROCESSING fails, that narrows the command policy substantially. If 95-105 s sweeps are all clean, the 100 s constant becomes less likely to be the initiating field cause even though it remains an architectural concern for longer modes.

Do not publish only crashes; publish discriminating non-crashes too.
