```bash

  D=/app/lib/stage2
```

  Scope it to the gphoto2 call only.

  in one SSH session right after the stop.
- Interpret per AGENTS.md ownership rule: direct CLI FAIL → libgphoto2 fork;
  direct PASS + packaged path FAIL → patcher/Stage-2; both pass + app fails →
  OpenPolaris. Compare first divergent PTP op, not final GP numbers.

## 4. 9090 wire protocol cheat sheet (from OpenPolaris `CommandBuilder.kt`)

Frame: `1&<code>&<subtype>&<payload>#` — payload is `key:value;` or empty.
Send with `printf '…' | nc -q1 192.168.0.1 9090`.

| Code | Meaning | Notes |
|---|---|---|
| 266 subtype 0, payload `-100` or empty | keepalive ping / camera-state GET | `val[-100]` = no-data sentinel; also the ~2.7 s poll seen in Clog |
| **274** | **camera live-view toggle**: payload `state:1;` ON, `state:0;` OFF | This is "the signal to disable liveview" — send `1&274&2&state:0;#`. (OpenPolaris's own code table calls 274 a color GET, but the device logs show polestar_app using type[4] code[274] `state:0/1` as the preview toggle — trust the device log.) |
| 286 | camera info push (`manufacturer;model;state;storage;photoFormat`) | `state:1` healthy, `-53` claim race, `-2` init fail |
| 291 / 292 | liveview SET/GET per OpenPolaris decompile (SP_SET_CAMERA_PREVIEW) | 274 is what the stock app actually logs; verify which one a given build answers before relying on it |

**Live-view rules (user directive):** if you can still SSH, LV is almost
certainly off — don't worry about it. When LV IS on: it is a processor/radio
load trigger (Broadcom `No more free tdata_psh_info` pool exhaustion has taken
the AP/SSH/BT down together). Do NOT enable Polaris live-view while the Benro
Connect app runs on the iPad — it kills that app.

## 8. Gotchas list (each one cost real time)

- Runtime model strings are SPACE-form (`'Pentax K-1 Mark II (PTP mode)'`), colon-form is CLI-only — the bug that made o-v7 shims inactive.
- Busybox on device: `grep -a`, no `tail -a`; logs contain ANSI codes — strip with `sed 's/\x1b\[[0-9;]*m//g'`.
- `scp` from the device often fails (no SFTP) → `ssh … 'tar czf - …' | tar xzf -`.
- GP error ranges: generic `0..-99` (`-2` BAD_PARAMETERS, `-6` NOT_SUPPORTED), camera-level from `-102`; 9090 app-level codes like `-1005` are polestar_app state, not GP.
- Watchdog ~30 s pgphoto relaunch; `restart_gphoto` is the only sanctioned restart helper (`stop_gphoto` doesn't exist).
- A `-53` right after a direct-CLI test = USB claim race with your own CLI; one more `/app/restart_gphoto` recovers it.
- Host udev rule `/etc/udev/rules.d/99-pentax-mtp-ignore.rules` (25fb → ID_MTP_DEVICE=0) must stay intact for direct PC tests.
